# （書き方の例）入門1 チャタリングを測る（スイッチ S1）

> これは書き方の例です。数値は説明のための架空の値です。
> 「うまくいかないとき」の表に当たった行は、**症状をそのまま**書き、表のどの行かと、何をしたら直ったかを残します。

- 日付：2026-11-20
- 章：intro1（入門1-6 段階5）

## 目的
タクトスイッチ S1 を50回押し、押す・離すごとのチャタリングの継続時間の分布を見る。

## 条件
- `bounce_capture.py --switch S1 --presses 50`（Pico A の main.py は bounce_logger.py）
- 押し方：人差し指で、1秒に1回くらい

## 配線
- GP14 → 行19 → スイッチの対角の足 → GND（手順19 で「中でつながっている組」を確かめた）

## 結果
- 期待（入門1-7）：エッジ1個（継続時間 0µs）の押下もかなりある。起きたときは数十µs〜1ms 程度が多い
- 実際：50回のうち押すときに起きたのは 19 回、継続時間の中央値は 180µs
- 「99%点の上限」は 50 回では「決まらない」と出た（期待どおり）
