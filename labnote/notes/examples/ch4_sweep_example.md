## 目的
デューティ 0〜100% を 10% きざみ・ランダムな順に2回ずつ回し、動き出すデューティ u0 と全速の回転数を測る。
回転数がデューティに比例しない（不連続導通）ことを自分のデータで確かめる。

## 条件
- 電池：単4 ニッケル水素 4本（RUN の前に測って 5.38V）。2A ヒューズ・非常停止あり
- `motor_run.py sweep --ms 3000 --rep 2 --order random --seed 1 --out data/sweep_1.csv`
- PWM 1kHz、負荷なし、室温 21℃
- Pico B のファーム：motor.c（教科書の版のまま。変えた所なし）

## 配線
- 4-4 の配線チェックリストは全部済み。C2 も付けた
- 写真：`data/0012/wiring_top.jpg`（上から）

## 結果
- 期待（4-7）：u0 は 10〜20% 程度、全速 200〜280RPM 程度
- 実際：u0 は 100‰ と 200‰ の間、全速は約 240RPM（2回の差 3RPM）
- 20% で全速の約半分、70% で 9割以上。比例しない（不連続導通の説明どおり）
- 電池側の電流は無負荷で 60mA 前後で、デューティにほとんどよらない

（ここに `labnote add-result` や bot の `/結果` で、CSV の要約と図が自動で足されます）

## 気づき
- 2回目の途中で `I,stall` が出て止まった。→ 4-7 の表の「I,stall」の行。
  出力軸の旗のテープが軸受けに触れていた。非常停止 → テープを短く貼り直す → `motor_run.py clear` →
  `run --d1 500 --ms1 2000` で確かめてから続けた（4-3-10 の順番どおり）
- 電池の電圧は RUN のあとに 5.21V。次は RUN ごとに測ってノートに書く
